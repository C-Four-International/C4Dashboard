## OVERVIEW & FEATURES


The C4 Monitoring Dashboard builds on the pre-existing core featureset of World Monitor, introducing 

custom enhancements tailored for our organization's use cases:

- Real-time event aggregation and data feeds.

- Enhanced map overlays and filtering capabilities.

- Customized UI layout optimized for quick intelligence parsing.

- Open and accessible architecture for community transparency.

## GETTING STARTED / LOCAL DEVELOPMENT


To run a local instance of C4 Dashboard:



1. Clone the repository:

   git clone https://www.github.com/C-Four-International/C4Dashboard <directory to install>



2. Navigate to the project directory:

   cd <directory to install>



3. Install dependencies:

   npm install  (or yarn install)



4. Configure your environment variables (refer to .env.example).



5. Run the development server:

   npm run dev
